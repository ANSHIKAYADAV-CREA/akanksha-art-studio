# 🎨 Akanksha Art Studio

A modern artist portfolio and online art studio designed to showcase
paintings, artwork, poetry, and creative work.

## ✨ Features

- 🎨 Art Gallery
- 🛍️ Online Art Store
- 🖼️ Painting Showcase
- ✍️ Poetry Section
- 📅 Booking System
- ⭐ Reviews
- 📩 Contact Section
- 🔐 Admin Panel
- 🔥 Firebase / Firestore Integration
- 🚀 Express Backend

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Firebase
- Cloud Firestore

## 👩‍🎨 About

Akanksha Art Studio is a creative portfolio and online platform
for showcasing artwork and connecting with art lovers.
